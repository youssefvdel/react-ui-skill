# MetallicPaint
**Registry**: `MetallicPaint-TS-TW` · **Deps**: none · **Files**: MetallicPaint/MetallicPaint.tsx
**What it does** — Renders liquid chrome reflections and flowing specular ripples across an input logo image or rendered text string via a custom WebGL2 shader. Specular bands warp with simplex noise, edge-bending distortion, and chromatic dispersion, reacting to cursor tilt.
**Props** — `imageSrc` (string, undefined) — image URL to rasterize into the metallic silhouette mask; `text` (string, undefined) — fallback text rendered onto a canvas mask when no image is provided; `color` (string, '#ffffff') — tint color applied across the specular chrome highlights; `backgroundColor` (string, 'transparent') — base background fill behind the metallic silhouette; `density` (number, 2) — repetition density of metallic reflection contour bands; `dispersion` (number, 0.3) — chromatic aberration separation along highlight edges; `distortion` (number, 0.07) — amplitude of simplex noise warping the reflection flow; `speed` (number, 1) — velocity of the flowing specular highlight ripple animation.
**Motion** — WebGL2 fragment shader evaluating procedural simplex noise, reflection bands, and RGB chromatic shifts in a continuous requestAnimationFrame loop. Mouse movement tilts the reflection normal vector. Mounts with an intro wipe reveal. WebGL2 only — no GSAP or Framer Motion. Reads `prefers-reduced-motion` at mount: the intro wipe is skipped and the shader never advances, so reduced motion gets one still frame.
**Cost** — 836 lines (~30 KB source), zero dependencies. High GPU fragment cost due to multi-tap 3×3 texture sampling for edge blurring, procedural noise, and chromatic aberration passes. Client-only: prerender emits an empty wrapper div; WebGL2 canvas initializes inside useEffect.
**Fit for ARKRETE** — no fit. Liquid chrome typography with iridescent rainbow dispersion and constant surface warping is a Y2K/crypto aesthetic that destroys ARKRETE's dark luxury world of bone ink, physical timber, and single brass accent.
**Verdict** — skip — liquid chrome shader aesthetic directly clashes with ARKRETE's restrained architectural bone/brass materiality.
