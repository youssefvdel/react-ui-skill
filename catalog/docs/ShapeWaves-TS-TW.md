# ShapeWaves
**Registry**: `ShapeWaves-TS-TW` · **Deps**: vgpu@^0.3.1 · **Files**: ShapeWaves/ShapeWaves.tsx
**What it does** — A full-bleed WebGPU grid of small triangles, circles and squares whose size and tint follow a drifting noise field, so bands of the grid swell and brighten as they roll across. Given `text`, the marks are omitted where the letters fall, so the wordmark reads as a hole in the field that lights up as the pointer passes.
**Props** — `text` (string, '') — glyphs knocked out of the grid; `shapes` ('mixed' | 'squares' | 'circles' | 'triangles', 'mixed') — the mark; `cellSize` (number, 10) — px per cell, so the density; `dotSize` (number, 0.75) — mark size inside the cell; `color` / `hoverColor` (string, #929292 / #ffffff) — rest and charged tint; `brightness` / `contrast` (number, 0.4 / 1) — how much of the noise band survives; `interactive` (boolean, true) — pointer ripples; `glow` (number, 0.35) — additive bloom strength.
**Motion** — A WGSL fragment shader on `vgpu`, drifting the noise field with time and `flow`; pointer movement adds Gaussian bumps to a CPU wave simulation (Laplacian, friction 0.94, decay 0.972) stepped at 60 Hz and uploaded as a storage buffer, which is what brightens cells toward `hoverColor`. The intro sweeps the grid in radially with a noise warp and a small overshoot. Offscreen, hidden, paused or reduced motion renders one static frame and stops.
**Cost** — `vgpu` is 57 KB gzip at 0.3.1 with eleven transitive dependencies and a 0.x API already at 0.6 — a young library for one effect. 928 lines / 32 KB of source. A full-screen shader at DPR 2, a half-res two-pass blur for the bloom, and ~13k cells of CPU wave simulation at up to four substeps a frame while ripples live. Client-only and WebGPU-only: async init, no fallback content, one flat rectangle on a browser that fails.
**Fit for ARKRETE** — No fit. The only page that could carry it is the home hero, and the hero is a photograph with the wordmark over it; the site's whole argument is the rooms, and this replaces them with an abstraction. LiveMark already owns the mark's entrance and would have to be thrown away.
**Verdict** — skip — the hero photograph is the pitch; a shader in its place trades evidence for a demo at 57 KB.
