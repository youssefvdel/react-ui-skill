# ColorBends
**Registry**: `ColorBends-TS-TW` · **Deps**: three@^0.180.0 · **Files**: `ColorBends/ColorBends.tsx`
**What it does** — Fills its box with a WebGL fragment shader that draws smooth, saturated colour bands which fold and drift like oil on water. Moving the pointer pulls the band field toward the cursor with a lerped parallax.
**Props** — `colors` (string[], []) — up to eight hex stops; empty falls back to a pure RGB channel split. `speed` (number, 0.2) — drift rate. `rotation` (number, 90) — band axis in degrees. `warpStrength` (number, 1) — how hard the bands fold. `frequency` (number, 1) — band density. `mouseInfluence` (number, 1) — pointer pull. `noise` (number, 0.15) — per-pixel grain. `transparent` (boolean, true) — alpha from band coverage instead of opaque black.
**Motion** — A continuous `requestAnimationFrame` loop advances `uTime` and eases the pointer uniform every frame; nothing waits for scroll or hover, it is always running while mounted. Needs three.js and a live WebGL context; there is no reduced-motion branch, so it animates even when the user asked it not to (`speed={0}` is the only manual freeze).
**Cost** — three@0.180 is a new dependency on a site that currently ships none of it; a bare renderer plus one shader material is roughly 40–50 KB gzip even after tree-shaking, and the full-screen fragment loop runs at DPR up to 2 forever. One canvas, no DOM churn. Effect-only, so prerender emits an empty div with no height — client-only in practice, and the parent must give it explicit dimensions.
**Fit for ARKRETE** — No fit. The only full-bleed surfaces are the home reel and the project photography, and both lose to saturated gradient colour; it also introduces a second colour world beside the single brass accent.
**Verdict** — skip — a permanent shader and a rainbow palette for a slot that belongs to photographs.
