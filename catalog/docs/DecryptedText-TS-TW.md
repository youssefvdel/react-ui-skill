# DecryptedText
**Registry**: `DecryptedText-TS-TW` · **Deps**: `motion@^12.23.12` · **Files**: `DecryptedText/DecryptedText.tsx`
**What it does** — Each character of a line flickers through random glyphs and then settles into the real letter, either all at once, one letter at a time, or outward from a point. The finished line is real text: a hidden copy sits in the DOM for screen readers.
**Props** — `text` (string, required) — the line · `speed` (number, `50` ms per tick) — scramble rate · `maxIterations` (number, `10`) — ticks before it resolves · `sequential` (boolean, `false`) — resolve letter by letter instead of all at once · `revealDirection` (`'start' | 'end' | 'center' | 'random'`, `'start'`) — order of resolution · `animateOn` (`'hover' | 'view' | 'click' | 'inViewHover'`, `'hover'`) — trigger · `effect` (`'scramble' | 'flip' | 'fade'`, `'scramble'`) — how the swap is drawn · `characters` (string, A–Z a–z punctuation pool) — the glyphs used.
**Motion** — A `setInterval` swaps glyphs from the pool until the mask resolves; substitute glyphs are measured on a canvas and scaled so the line never reflows. `flip` adds a Web Animations rotateX on each cell, `fade` dims the unresolved ones. Triggers on hover, in-view, click, or in-view-then-hover; reduced motion reveals the text instantly and never starts the interval.
**Cost** — Depends on `motion@^12.23.12`, but the only use is a `<motion.span>` wrapper — no motion API is called, so the dependency is dead weight and the file would work as a plain span. 19.8 KB source (5.6 KB gzip); one span per character plus a hidden glyph while scrambled; the interval only runs during a reveal.
**Fit for ARKRETE** — No fit. A hacker-style decryption read belongs to a security product, not to a fit-out firm's quiet pages.
**Verdict** — skip — a tech demo that ships a full animation library to render a `span`.
