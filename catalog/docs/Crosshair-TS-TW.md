# Crosshair
**Registry**: `Crosshair-TS-TW` · **Deps**: none · **Files**: `Crosshair/Crosshair.tsx`
**What it does** — Lays a full-viewport crosshair over the page that tracks the pointer on a canvas, tags its x and y in ten-pixel mono, and snaps corner brackets around any link or button it crosses, labelling that element's pixel size. Clicking throws a ring, and it can hide the native cursor entirely.
**Props** — `color` (string, #ffffff) — ink for lines, tags and brackets. `thickness` (number, 1) — line weight. `lineStyle` ('solid' | 'dashed' | 'dotted', 'solid') — stroke pattern. `gap` (number, 0) — hole left at the intersection. `showCoordinates` (boolean, true) — the x/y tags and size readout. `targetEffect` ('lock' | 'glitch' | 'none', 'lock') — bracket behaviour over links. `targetSelector` (string, 'a, button, [data-crosshair-target]') — what counts as a target. `hideCursor` (boolean, false) — suppress the native cursor while inside.
**Motion** — A 2D canvas loop that runs only while the crosshair is settling: smoothed follow, presence fade, bracket lerp, glitch jitter and click rings. Under reduced motion the follow snaps, the glitch is dropped and pulses are suppressed. No library, no WebGL.
**Cost** — Zero dependencies, ~16 KB source, but it injects a global `cursor: none` rule (applied only while `hideCursor` is on) and mounts a fixed canvas at `z-index: 10000` across the whole document; redraw is full-canvas at DPR up to 2 on each frame. Client-only — prerender produces an empty zero-size canvas.
**Fit for ARKRETE** — No fit. Mono coordinate tags and a targeting reticle are a technical register the brand explicitly avoids, and the reticle competes with the brass accent on every page.
**Verdict** — skip — a HUD skin, not motion with a job.
