# Masonry
**Registry**: `Masonry-TS-TW` · **Deps**: `react-dom@^19.0.0`, `@hugeicons/react@^1.1.10`, `@hugeicons/core-free-icons@^4.3.3` · **Files**: Masonry/Masonry.tsx
**What it does** — Lays out photos in an auto-packing multi-column masonry wall that springs into place on mount and reflows dynamically during viewport resize. Cards lift or tilt under the cursor, can be dragged to reorder, and open full-screen within an animated lightbox modal with icon navigation.
**Props** — `items` (MasonryItem[], []) — array of gallery items with image source, aspect ratio, title, and link; `columns` ('auto' | number, 'auto') — explicit column count or automatic packing based on container width; `columnWidth` / `gap` (number, 260 / 16) — target column width and pixel spacing between items; `animateFrom` ('bottom' | 'top' | 'left' | 'right' | 'center' | 'random' | 'none', 'bottom') — entrance direction vector; `hoverEffect` ('zoom' | 'lift' | 'tilt' | 'none', 'lift') — interactive card hover transformation; `captions` ('hover' | 'always' | 'none', 'hover') — visibility trigger for overlay title and description text; `lightbox` (boolean, true) — whether clicking an item launches a full-screen image viewer; `draggable` (boolean, false) — enables pointer drag gestures to reorder cards dynamically.
**Motion** — Custom JS spring physics running in rAF for layout reflow, entrance staggering, and drag-and-drop tracking. CSS 3D transforms handle hover tilt and lift. Lightbox uses FLIP-style transform interpolation via a React portal. No GSAP or Framer Motion required.
**Cost** — 1,170 lines (~44.5 KB source) plus Hugeicons dependencies. High DOM and scripting cost: every tile is absolutely positioned via JavaScript layout math, measuring images and recalculating spring physics on rAF. Client-only layout calculation: server prerender outputs unmeasured absolute divs that shift on client mount.
**Fit for ARKRETE** — no fit. ARKRETE presents projects as a calm, cinematic vertical scroll stack of rooms where each room commands the screen; a dense Pinterest-style multi-column masonry grid with bouncy spring physics and drag-to-reorder cheapens high-end interior spaces into social-media tiles.
**Verdict** — skip — multi-column bouncy masonry grid and icon dependencies contradict ARKRETE's calm room-by-room scroll stack.
