# TechText
**Registry**: `TechText-TS-TW` · **Deps**: none · **Files**: `TechText/TechText.tsx`
**What it does** — Draws a wordmark on a 2D canvas where letters near the pointer dissolve into dashed vector outlines and back, with optional selection handles, dimension ticks and drifting specks. Letters can be dragged and settle with a bounce, and the intro can type, assemble or draw measurement guides.
**Props** — `text` (string, `React Bits`) — the word; `fontFamily` / `fontWeight` / `fontSize` / `letterSpacing` — type, defaulting to the container's font; `color` / `accentColor` (string, currentColor) — fill and outline; `reach` (number, 200) — pointer radius; `softness` (number, 0.7) — edge falloff; `dashLength` / `dashGap` / `strokeWidth` / `lineStyle` (`dashed`|`solid`) — the vector look; `reveal` (`area`|`letter`|`off`, letter) — how letters convert; `selection`, `labels`, `guides`, `draggable` (booleans, true/true/false/true) — the designer-tool furniture.
**Motion** — Continuous 2D canvas repaint while the pointer is inside: a lens region converts covered pixels into cached per-glyph dashed sprites, plus spring-settled drag and an optional intro. No WebGL, no animation library; reduced motion draws once and stays still.
**Cost** — No dependency, ~38 KB source, one canvas plus an offscreen sprite canvas per glyph at DPR — real memory and repaint cost on a large wordmark. Renders `role="img"` with `aria-label`, so the text is a picture: it cannot be the `h1`, cannot be selected and gives crawlers no heading.
**Fit for ARKRETE** — no fit. The home monument wordmark must stay real type in bone ink; the dashed-path, tick-label, selection-handle language is exactly the blueprint/mono-label look the brand rules out.
**Verdict** — skip — a canvas wordmark that turns the one piece of type the site is built around into an image with tool chrome.
