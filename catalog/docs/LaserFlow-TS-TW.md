# LaserFlow
**Registry**: `LaserFlow-TS-TW` · **Deps**: none · **Files**: `LaserFlow/LaserFlow.tsx`
**What it does** — Projects a vertical laser beam straight down onto a DOM element or horizontal surface level, where it impacts, blooms, and pours glowing liquid-light spills along the top edge. The beam tracks cursor horizontal movement and can burn through to reveal an underlying image through the light wash.
**Props** — `surfaceRef` (RefObject<HTMLElement | null>) — target element whose top bounds receive and spread the beam; `beamPosition` (number, 0.6) — horizontal beam origin ratio across width; `color` (string, '#3847ff') — core laser tint; `intensity` / `flare` (number, 1.8 / 1.5) — beam brightness and impact bloom radius; `beamWidth` / `spread` (number, 1.5 / 1.5) — beam thickness and lateral spill distance; `fog` / `dust` (number, 0.2 / 1.6) — atmospheric mist density and particle streaks; `mouseInteraction` (boolean, true) — whether cursor horizontal position steers the beam; `revealImage` (string) — optional image masked into the illuminated pool.
**Motion** — Fullscreen WebGL2 fragment shader running procedural FBM noise, streak calculations, and atmospheric bloom each frame on rAF; cursor X updates beam alignment. No external animation libraries. Reduced motion pauses shader time progression and mouse steering, parking the beam in place.
**Cost** — Zero dependencies; 35.6 KB source (~7.5 KB gzip). Heavy WebGL2 fragment shader evaluating multiple noise octaves and bloom curves per fragment; high GPU fill cost. Client-only; prerenders an empty div.
**Fit for ARKRETE** — no fit. Sci-fi neon laser beams and glowing liquid spills are alien to an architectural interior fit-out firm.
**Verdict** — skip — sci-fi neon laser spill that has no place in quiet interior architecture.
