# PixelCard
**Registry**: `PixelCard-TS-TW` · **Deps**: none · **Files**: `PixelCard/PixelCard.tsx`
**What it does** — A card container backed by an HTML5 2D canvas that renders an animated field of shimmering pixel glyphs. Hovering or focusing sweeps a radial spotlight across the card that scatters sparkling squares, circles, or diamonds.
**Props** — `variant` ('default' | 'blue' | 'yellow' | 'pink', 'default') — colour and timing preset; `colors` (string | string[], preset defaults) — palette for the sparkling pixel glyphs; `gap` (number, 5) — spacing between pixel cell centers; `speed` (number, 35) — shimmer rate and phase oscillation frequency; `pixelSize` (number, 2) — base size of individual pixel shapes; `shape` ('square' | 'circle' | 'diamond', 'square') — pixel glyph silhouette; `origin` ('center' | 'pointer', 'center') — starting focal point of the spotlight reveal; `trigger` ('hover' | 'click' | 'always', 'hover') — event that wakes the spotlight and pixel shimmer.
**Motion** — An HTML5 2D canvas requestAnimationFrame loop iterating over Float32Array typed arrays for particle positions, phase, and jitter. Hover updates spotlight focus, clicks trigger radial shockwave pulses, and time modulates sparkle phase; reduced motion halts the loop and draws a static state.
**Cost** — 23.7 KB source (~4.5 KB gzip), zero dependencies. One `<canvas>` element inside a card container. Canvas 2D CPU drawing loop running continuously on hover, compounding cost across multiple cards. Children prerender on the server, but the canvas background is client-only.
**Fit for ARKRETE** — No fit. Shimmering pixel sparkle cards read as crypto or gaming UI, disrupting the presentation of high-end physical materials and rooms.
**Verdict** — skip — gaming/crypto pixel glitter card background that adds CPU drawing loops to portfolio cards.
