# StrokeText
**Registry**: `StrokeText-TS-TW` · **Deps**: `gsap@^3.13.0` · **Files**: `StrokeText/StrokeText.tsx`
**What it does** — Sets a line of text as per-character SVG outlines, animates the stroke dash so the letterforms draw themselves on, then floods the fill through a wiping clip rect. Optional dashed or dotted strokes leave the letters as line drawings, with marching ants and a drop shadow.
**Props** — `text` (string, `Draw Attention`) — the line; `strokeColor` (string, #A78BFA) and `fillColor` (string, currentColor) — outline and flood; `strokeWidth` (number, 1.4) — pen weight; `drawDuration` (number, 1.6), `stagger` (number, 0.05), `fillDelay` (number, 0.2) — timing; `trigger` (`mount`|`hover`|`scroll`|`loop`, mount) — what starts it; `fillMode` (`wipe`|`fade`|`none`, wipe) with `wipeFrom` — how colour arrives; `fontSize` (number, 128), `fontWeight`, `letterSpacing`, `fontFamily` — type; `hoverRedraw`, `marching`, `shadow` — small extras.
**Motion** — A paused GSAP timeline draws stroke-dashoffset, then wipes the fill; `scroll` arms a one-shot ScrollTrigger at `top 82%`, `hover` replays on pointer enter, `loop` yoyos forever. With reduced motion it jumps straight to the finished state. Requires GSAP plus ScrollTrigger.
**Cost** — `gsap` + `gsap/ScrollTrigger`, roughly 35–40 KB gzip together, plus ~15 KB of source; one inline SVG with a path per character, filter and mask defs, and a measured bounding box. Renders `role="img"` with an `aria-label`, so the line is not real heading text — pair it with a hidden `h2` or accept the SEO loss. Client-measured but SSG-safe (SSR emits a hidden svg until layout runs).
**Fit for ARKRETE** — services, the five-trades intro heading: brass stroke drawing on, then filling to bone, once on scroll. Nowhere else — the home wordmark must stay type, and project titles need to be selectable.
**Verdict** — adapt — one services heading, code-split with GSAP, brass-to-bone; drop it if GSAP is not already in the bundle.
