# BorderGlow
**Registry**: `BorderGlow-TS-TW` · **Deps**: none · **Files**: BorderGlow/BorderGlow.tsx
**What it does** — A card whose 1px border becomes a mesh gradient that lights up only on the arc nearest the pointer, with a matching tint bleeding a few pixels into the fill and a soft bloom outside the edge. With `animated` it runs the same sweep on its own once after mount.
**Props** — `colors` (string[], `#c084fc`, `#f472b6`, `#38bdf8`) — the three mesh stops; `edgeSensitivity` (number, 30) — how close to the edge the rim starts to show; `glowColor` (string, HSL triplet `40 80 80`) — outer bloom hue; `backgroundColor` (string, `#120F17`) — card fill; `borderRadius` (number, 28) — corner radius inherited by every layer; `glowRadius` (number, 40) — px the bloom extends beyond the card; `coneSpread` (number, 25) — width of the lit arc; `animated` (boolean, false) — one automatic sweep on mount.
**Motion** — Pointer-driven with no library: every `pointermove` sets React state for angle and edge proximity, which drives two conic-gradient masks and a 13-layer inset/outset box-shadow; opacity eases in over 0.25s and out over 0.75s. `animated` chains four rAF-eased timers for a 4.5-second sweep. There is no reduced-motion check at all — the automatic sweep still runs.
**Cost** — No dependencies, about 3 KB gzipped source. Three stacked absolute layers per card, `mask-composite` with the `-webkit-` fallback, `plus-lighter` blending and a 13-shadow stack; each pointer move re-renders the card and repaints two masked gradients, which is noticeable in a grid of cards. Prerenders fine because the layers start at opacity 0.
**Fit for ARKRETE** — No fit — a purple, pink and blue mesh rim introduces two more accents and a soft-light fill that has nothing to say about interiors.
**Verdict** — skip — hover decoration with no job, a palette that breaks the one-brass rule, and no reduced-motion path.
