# SwipeToast
**Registry**: `SwipeToast-TS-TW` · **Deps**: `motion@^12.23.12`, `@hugeicons/react@^1.1.10`, `@hugeicons/core-free-icons@^4.3.3` · **Files**: `SwipeToast/SwipeToast.tsx`
**What it does** — A dark toast card that slides in with a title, line of description and an optional action, and burns a thin horizontal fuse along its edge to show the time left. It pauses on hover, focus or a hidden tab, and can be flicked down or swiped away to dismiss.
**Props** — `title` / `description` (ReactNode, `File archived` / empty) — copy; `actionLabel` / `onAction` — the single action; `open` (boolean, true) with `onClose(reason)` — controlled lifecycle; `duration` (number, 4000) — fuse length in ms; `fuse` (`bottom`|`top`|`none`, bottom) and `fuseColor` (string, #f5a524) — the timer strip; `swipeDistance` (number, 40) — travel needed to dismiss; `inline` (boolean, false) — reserve space instead of overlaying; `pauseOnHover` (boolean, true) — hold the fuse.
**Motion** — The card enters and exits with motion/react springs and drag on the y axis; the fuse is a CSS `scaleX` keyframe animation driven through the Web Animations API so it can pause and resume. Reasons are reported as `timeout`, `swipe`, `action`, `close`, `escape` or `programmatic`; reduced motion closes instantly.
**Cost** — `motion` plus two hugeicons packages (~30–40 KB gzip for motion, icons tree-shaken to one), ~16 KB source. Fixed or inline positioning, no portal; timers and global listeners per toast. Server-safe render, client-only behaviour.
**Fit for ARKRETE** — contact, after the inquiry form submits — but a card with an orange burning fuse is the wrong register; a single inline confirmation line is calmer and needs no dependency.
**Verdict** — skip — the fuse makes a reply feel urgent, and the default orange is a second accent.
