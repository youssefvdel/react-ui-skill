# LatticeLoader
**Registry**: `LatticeLoader-TS-TW` · **Deps**: none · **Files**: `LatticeLoader/LatticeLoader.tsx`
**What it does** — Displays a 3×3 or 4×4 LED dot matrix that cycles through animated chase patterns beside an optional label and running tenths-of-a-second stopwatch. When status changes to done or error, the dots snap into a checkmark or cross and freeze with the final elapsed time.
**Props** — `status` ('working' | 'done' | 'error', 'working') — active state driving animation or completion glyph; `pattern` (LatticePatternName | LatticePattern, 'orbit') — dot lighting sequence ('orbit', 'sweep', 'ripple', 'snake', etc.); `grid` (3 | 4, 3) — matrix dimensions (9 or 16 dots); `shape` ('square' | 'round', 'round') — cell corner rounding; `color` / `doneColor` / `errorColor` (string, 'currentColor' / '#22c55e' / '#ef4444') — state colors; `cellSize` / `gap` (number, 6 / 2) — dot size and spacing in pixels; `label` / `doneLabel` / `errorLabel` (string, 'Thinking' / 'Done in' / 'Failed after') — screen reader and visible copy; `showTimer` (boolean, true) — whether to tick a running seconds counter.
**Motion** — Pure CSS `@keyframes` cycle cell opacity via inline custom properties and staggered delays; an interval timer directly updates DOM textContent for elapsed time without React state rerenders. No animation libraries. Reduced motion replaces sequential chases with a synchronized 1.4 s pulse and suppresses zoom transitions.
**Cost** — Zero dependencies; 11.3 KB source (~2.8 KB gzip). Extremely lightweight with only 9 to 16 DOM span elements and negligible CPU cost. Fully compatible with server prerendering, rendering static markup and inline CSS before hydrating.
**Fit for ARKRETE** — no fit. A digital LED matrix and stopwatch timer evoke a developer terminal or LLM chat interface, not a luxury fit-out studio.
**Verdict** — skip — a tech-terminal LED grid and elapsed-time stopwatch clash with quiet architectural luxury.
