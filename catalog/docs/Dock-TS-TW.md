# Dock
**Registry**: `Dock-TS-TW` · **Deps**: `react-dom@^19.0.0` · **Files**: `Dock/Dock.tsx`
**What it does** — A macOS dock: a translucent bar of icon tiles that swell as the pointer nears, bounce once when launched, and can carry badges, labels, active dots and multi-level context menus. It parks on any screen edge and can hide until the pointer reaches that edge.
**Props** — `items` (`{ icon, label, onClick, active, badge, menu }[]`, `[]`) — the tiles · `position` (`'bottom' | 'top' | 'left' | 'right'`, `'bottom'`) — which edge · `baseItemSize` (number, `50`) / `magnification` (number, `70`) — resting and hovered tile size · `distance` (number, `200`) — pointer range of the swell · `spring` (`{ mass, stiffness, damping }`, `{0.1, 150, 12}`) — magnification feel · `bounce` (boolean, `true`) — launch hop · `autoHide` (boolean, `false`) — slide away until edge hover · `tiles` / `showLabels` / `showIndicators` (boolean, `true`) — icon plate, tooltip, active dot.
**Motion** — A per-item spring integrator runs inside one rAF and writes width and height, so neighbours grow and shove each other aside in proportion to pointer distance. A click launches a hop, the panel slides on auto-hide, and menus animate in through a portal with an SVG clip path that morphs from the dock tile. Reduced motion is honoured through `motion-reduce` classes and a `reduce` check that disables the spring.
**Cost** — `react-dom@^19.0.0` for `createPortal`, plus 46.3 KB source (11.7 KB gzip) — the heaviest component in this batch. Menus render outside the tree and manage their own focus and keyboard navigation; the rAF only runs while something is moving. ARIA wiring is unusually complete for a demo component.
**Fit for ARKRETE** — No fit. A dock is an operating-system metaphor; the site needs a quiet header with five links, not a launcher.
**Verdict** — skip — the heaviest file in the batch for a metaphor that belongs to a desktop, not a fit-out firm.
