# CurvedLoop
**Registry**: `CurvedLoop-TS-TW` · **Deps**: none · **Files**: `CurvedLoop/CurvedLoop.tsx`
**What it does** — One line of text is set on an SVG path and scrolled along it, so the words bend around an arc, wave, ring or straight rule and loop without a seam. Dragging the line scrubs it by hand and throws it with the pointer's speed.
**Props** — `marqueeText` (string, `''`) — the repeated string · `shape` (`'arc' | 'wave' | 'circle' | 'line'`, `'arc'`) — the path it rides · `curveAmount` (number, `400`) — bow of the arc, amplitude of the wave · `speed` (number, `2`) — idle drift · `direction` (`'left' | 'right'`, `'left'`) — travel direction · `separator` / `separatorColor` (string, none) — a glyph between repeats, optionally the accent · `edgeFade` (number 0–1, `0`) — mask at both ends · `scrollBoost` (number, `0`) — adds scroll speed to the drift.
**Motion** — A requestAnimationFrame loop writes `startOffset` on every `<textPath>`; nothing is CSS-animated. Drag uses pointer capture with a fling that decays, and scroll velocity can feed the loop. Text width is measured via `getComputedTextLength`, re-measured on `fonts.ready` and resize; reduced motion zeroes the speed, and the loop pauses when offscreen.
**Cost** — No dependencies, 15.3 KB source (4.7 KB gzip). The DOM holds one `<text>` copy per repeat needed to cover the path — a circle can run to dozens of copies. The wrapper forces `min-h-screen` and the SVG hard-codes `uppercase`, both of which fight the site. Prerender-safe, but the whole block stays `visibility: hidden` until measurement runs on the client.
**Fit for ARKRETE** — No fit. The home already carries the monument wordmark, and a second moving line of uppercase type breaks both the sentence-case rule and the stillness the hero depends on.
**Verdict** — skip — moving uppercase marquee with a full-viewport wrapper and no job on the page.
