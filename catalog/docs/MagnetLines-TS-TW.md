# MagnetLines
**Registry**: `MagnetLines-TS-TW` · **Deps**: none · **Files**: MagnetLines/MagnetLines.tsx
**What it does** — Fills the container with an instanced grid of needle, arrow, or line markers that pivot in unison toward the cursor. A click dispatches an expanding radial ripple wave, while idle springs relax each line back to its resting angle.
**Props** — `mode` ('orbit' | 'attract' | 'spiral' | 'dipole', 'orbit') — field orientation algorithm guiding line rotation; `shape` ('line' | 'arrow' | 'needle', 'line') — geometry drawn for each grid element; `lineColor` (string, '#efefef') — default unaccented stroke color; `accentColor` (string, undefined) — optional accent highlighting markers near the pointer; `spacing` (number, 30) — pixel gap between adjacent line pivots in the grid; `lineWidth` / `lineHeight` (number | string, 2 / 18) — dimensions of each individual marker; `baseAngle` (number, -10) — rest orientation in degrees when unaffected by the cursor; `clickPulse` (boolean, true) — whether clicking sends an outward rotational impulse wave.
**Motion** — Instanced WebGL2 shader pipeline rendered on requestAnimationFrame. Pointer coordinates update the attraction center, lerping spring inertia, stretch, and bounce; clicks trigger a radial shockwave; mounts with an intro wave. WebGL2 only — no GSAP, Framer Motion, or three.js. Reads `prefers-reduced-motion` at mount: the intro, the idle wander, spring stiffness, ripple lag and the click pulse are all dropped, and the rAF loop sleeps whenever the field is stable.
**Cost** — 1,105 lines (~39 KB source), zero dependencies. Uses raw WebGL2 instanced arrays and custom matrix math, rendering hundreds of geometric markers at up to 2× DPR. Client-only: SSR emits an empty container div with an aria-hidden canvas; initializes WebGL context inside useEffect.
**Fit for ARKRETE** — no fit. A playful magnetic pointer field is interactive gadgetry suited for a creative tech portfolio; ARKRETE's dark, quiet architectural world demands that photography carries the space without distracting cursor gimmicks.
**Verdict** — skip — interactive magnetic compass gimmick that adds decorative noise without supporting architectural spaces.
