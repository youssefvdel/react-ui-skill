# LightTunnel
**Registry**: `LightTunnel-TS-TW` · **Deps**: none · **Files**: `LightTunnel/LightTunnel.tsx`
**What it does** — Simulates a cylindrical fiber-optic tunnel where bright light pulses race along curved cables into depth or outward. Moving the cursor bends the tunnel trajectory and shifts camera perspective, while clicking launches an accelerated brightness surge down the lines.
**Props** — `cableColor` / `pulseColor` (string, '#ffffff' / '#ffffff') — base guide cables and travelling pulse tints; `tunnelColor` / `tunnelOpacity` (string / number, '#ffffff' / 0) — outer cylinder shell color and opacity; `speed` / `pulseSpeed` (number, 0.1 / 2) — cable rotational roll and pulse travel velocity; `flowDirection` ('inward' | 'outward', 'inward') — travel direction along the tunnel; `cableCount` / `thickness` (number, 56 / 0.35) — number of longitudinal lines and line thickness; `waviness` / `sway` / `bend` (number, 0.3 / 0.5 / 0.4) — cable oscillation, camera sway, and cursor-driven curvature; `pulseLength` / `pulseDensity` (number, 0.28 / 0.5) — pulse comet length and frequency; `mouseInteraction` / `clickSurge` (boolean, true / true) — cursor parallax bending and click acceleration.
**Motion** — WebGL2 fragment shader evaluating cylindrical coordinate projections, sinusoidal cable bending, and pulse progress on rAF; mouse coordinates lerp the camera pivot. No external libraries. Reduced motion zeroes pulse motion and time progression, freezing cables in a resting perspective.
**Cost** — Zero dependencies; 20.1 KB source (~5 KB gzip). Single WebGL2 canvas element; moderate per-fragment trigonometry load. Client-only; prerenders an empty container.
**Fit for ARKRETE** — no fit. A sci-fi hyperspace fiber-optic tunnel has nothing to do with quiet architectural fit-out.
**Verdict** — skip — sci-fi warp-tunnel spectacle with zero connection to architectural fit-out.
