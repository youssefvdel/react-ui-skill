# Lanyard
**Registry**: `Lanyard-TS-TW` · **Deps**: three · **Files**: `Lanyard/Lanyard.tsx`
**What it does** — Renders an interactive 3D ID badge suspended from a fabric lanyard strap anchored to the top of the canvas. The card sways in simulated gravity and breeze, and can be grabbed, dragged, flicked, and twisted in space with the pointer.
**Props** — `frontImage` / `backImage` (string) — card face textures; `cardColor` (string, '#ffffff') — plastic base tint; `orientation` ('portrait' | 'landscape', 'portrait') — badge aspect ratio; `finish` ('glossy' | 'matte' | 'holographic' | 'metallic', 'matte') — card shader material; `strapLength` / `strapWidth` (number, 1 / 0.075) — lanyard strap dimensions; `strapColor` (string, '#18181b') — fabric ribbon color; `gravity` / `damping` / `elasticity` (number, 1 / 1 / 1) — Verlet rope and rigid-body physics tuning; `interactive` (boolean, true) — pointer dragging and release tossing.
**Motion** — Segmented Verlet particle integration drives the strap while 6DOF rigid-body dynamics simulate card momentum, air drag, and gravitational sway on rAF; pointer drags apply tension and flick impulses. Requires Three.js and WebGL. Reduced motion zeroes ambient breeze and skips the drop intro, but pointer physics still execute.
**Cost** — Requires `three@^0.180.0` (~160 KB gzip), exceeding the site's entire 150 KB initial bundle budget on its own; 52.8 KB source. Heavy continuous CPU physics integration and WebGL rendering loop. Client-only; prerenders an empty placeholder container.
**Fit for ARKRETE** — no fit. A 3D tech-conference credential badge has zero relevance to high-end interior architecture fit-out.
**Verdict** — skip — interactive 3D conference pass that drags Three.js into a site with a 150 KB total budget.
