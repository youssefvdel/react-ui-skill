# CircularText
**Registry**: `CircularText-TS-TW` · **Deps**: `motion@^12.23.12` · **Files**: CircularText/CircularText.tsx
**What it does** — Arranges characters of a text string along a circular perimeter and spins continuously like a stamp or seal. Hovering alters the rotation velocity or tilts the ring in 3D perspective, and users can grab and spin it with pointer drag.
**Props** — `text` (string, required) — text string distributed around the circle; `spinDuration` (number, 20) — duration in seconds for full 360-degree rotation; `onHover` ('slowDown' | 'speedUp' | 'pause' | 'goBonkers', 'speedUp') — hover reaction modulating rotational velocity; `direction` ('clockwise' | 'counterclockwise', 'clockwise') — rotation direction; `size` (number, 200) — circular container diameter in pixels; `startAngle` (number, 0) — initial rotational offset angle; `hoverTilt` (number, 0) — maximum 3D tilt angle on pointer hover; `draggable` (boolean, false) — enables pointer drag gestures.
**Motion** — Continuous time-based rotation driven by Framer Motion's `frame` loop, using `useMotionValue` and `useSpring` for rotation velocity, scale, and 3D tilt response. Reduced motion stops continuous spin and locks the text statically. Requires Framer Motion.
**Cost** — Requires `motion` (~30 KB gzip) plus 11 KB source; renders individual `<span>` elements per character with absolute positioning and transforms. Safe for prerender (static circle of letters), with motion hooking up on hydration.
**Fit for ARKRETE** — no fit. Arkrete mandates sentence case typography throughout and forbids uppercase mono labels or decorative badges; a spinning circular text badge is a dated agency trope.
**Verdict** — skip — spinning circular seal requires the heavy motion library for a decorative badge trope that violates Arkrete's typography rules.
