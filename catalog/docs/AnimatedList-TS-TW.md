# AnimatedList
**Registry**: `AnimatedList-TS-TW` · **Deps**: @hugeicons/react@^1.1.10, @hugeicons/core-free-icons@^4.3.3 · **Files**: AnimatedList/AnimatedList.tsx
**What it does** — A scrollable listbox in a padded frosted frame where rows outside the middle half of the viewport shrink, fade and slide off, then spring back as you scroll them in. Hovering or arrowing glides a 1px selection ring to the row and resizes it to that row's height.
**Props** — `items` (string | entry[], fifteen demo file rows) — rows with optional icon, image, description and right-hand meta; `renderItem` (fn, —) — replaces the whole row body; `animation` ('pop' | 'slide' | 'fade' | 'none', 'pop') — the hidden pose; `stagger` (number, 0.05) — seconds between rows on first entrance; `selectOnHover` (boolean, true) — pointer picks the row; `showGradients` (boolean, true) — masked fade at the scroll edges; `frame` (boolean, true) — the padded glass border; `accentColor` (string, theme ink) — selection ring and focus outline.
**Motion** — Pure CSS transitions plus one hand-written rAF spring for the ring: rows move 12–28px and scale 0.8–0.98 into place on a 620ms `linear()` spring curve, opacity in 300ms. An IntersectionObserver gates the first staggered reveal, then scroll re-runs it against row geometry. Reduced motion swaps everything for a 4px fade and snaps the ring into place.
**Cost** — No animation library; 641 lines / 24 KB of source. `@hugeicons/core-free-icons` is a 6.4 MB barrel — twelve icons tree-shake to a few KB, but the demo items are built at module load, so they only drop if you delete them. One scroll listener, one ResizeObserver, rAF only while the ring travels. Rows render with `opacity: 0` until the layout effect sets a state, so the prerendered HTML is an empty frame.
**Fit for ARKRETE** — No fit. The site has no list UI — services are an accordion strip, work is a scroll reel, the contact page holds a form and two addresses. This is a file-manager widget: frosted frame, thin scrollbar, icon tiles, gradient masks.
**Verdict** — skip — the gliding ring is forty lines of CSS you can own, and everything around it is app chrome the pages do not have.
