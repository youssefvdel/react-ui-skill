# Carousel
**Registry**: `Carousel-TS-TW` · **Deps**: `@hugeicons/react@^1.1.10`, `@hugeicons/core-free-icons@^4.3.3` · **Files**: Carousel/Carousel.tsx
**What it does** — Displays a swipeable slide deck supporting five distinct transition effects with pointer dragging, wheel scrolling, and navigation arrows. Slides feature background imagery, title overlays, and an optional autoplay progress bar indicator.
**Props** — `items` (CarouselEntry[], 5 demo items) — slide data array; `effect` ('tilt' | 'slide' | 'scale' | 'fade' | 'cube', 'tilt') — transition algorithm between slides; `indicator` ('dots' | 'bars' | 'counter' | 'none', 'dots') — pagination indicator style; `arrows` (boolean, true) — renders chevron navigation buttons; `autoplay` (boolean, false) — advances slides on a timer; `autoplayDelay` (number, 5000) — auto-advance delay in ms; `draggable` (boolean, true) — enables drag gestures; `loop` (boolean, true) — wraps navigation infinitely.
**Motion** — Custom rAF spring loop (stiffness 118, damping 18) updating `transform`, `opacity`, and `zIndex` per slide, plus `scaleX` on progress bars during autoplay. Triggered by pointer drag, wheel, button click, keyboard, or timer. Reduced motion snaps immediately to the target slide without spring physics; no external animation libraries.
**Cost** — 35 KB source code; `@hugeicons` dependency for controls; updates styles across active slide nodes on every frame while moving. Prerenders static slide markup safely, attaching interaction on client mount.
**Fit for ARKRETE** — no fit. Arkrete relies on scroll-driven reels and stacks for room photography; interactive sliders with tilt/cube transitions and progress bars add UI noise and break the editorial rhythm.
**Verdict** — skip — generic card slider with autoplay bars and 3D transforms adds unnecessary UI widgets over quiet scroll storytelling.
