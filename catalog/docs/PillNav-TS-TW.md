# PillNav
**Registry**: `PillNav-TS-TW` · **Deps**: none · **Files**: `PillNav/PillNav.tsx`
**What it does** — A floating navigation pill bar with an optional circular logo, text links, and an indicator dot or highlight pill that glides between items. On narrow viewports it collapses into a circular toggle that unfolds an absolute vertical sheet menu.
**Props** — `items` (PillNavItem[], four links) — navigation items with label, href, icon, and aria-label; `activeHref` / `defaultActiveIndex` (string / number, 0) — controlled or initial active link; `theme` ('dark' | 'light', 'dark') — surface, text, and highlight colour variables; `layout` ('split' | 'joined', 'split') — separate floating logo circle or single merged container; `surface` ('glass' | 'solid' | 'none', 'glass') — backdrop-blur glass, solid ground, or transparent track; `hoverEffect` ('fill' | 'glide' | 'none', 'fill') — radial fill bubble or sliding pill on hover; `indicator` ('dot' | 'pill' | 'none', 'dot') — active item marker style; `bounce` / `stretch` (number, 0.3 / 0.5) — spring overshoot and elongation feel.
**Motion** — A custom requestAnimationFrame spring integrator drives horizontal translation, width stretching, and press squash for the glide pill and active dot; CSS transitions handle radial fill bubbles and burger-to-cross line rotation. Triggered on hover, focus, press, and click without GSAP or Framer Motion. Reduced motion disables transitions and snaps spring states directly.
**Cost** — 37.3 KB source (~5.2 KB gzip), zero dependencies. Modest DOM footprint with an inverted ink text clip layer and mobile panel overlay. Prerenders cleanly with initial active styles, though track measurement and spring physics run on the client.
**Fit for ARKRETE** — No fit. ARKRETE's header avoids a floating slab over full-bleed photography, and the site keeps desktop navigation as a quiet typographic row rather than an animated SaaS pill dock.
**Verdict** — skip — floating pill bar with bouncy spring physics and mobile sheet that violates ARKRETE's groundless header rule.
