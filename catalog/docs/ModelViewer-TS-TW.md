# ModelViewer
**Registry**: `ModelViewer-TS-TW` · **Deps**: `@react-three/fiber@^9.3.0`, `@react-three/drei@^10.7.4`, `three@^0.180.0` · **Files**: ModelViewer/ModelViewer.tsx
**What it does** — Renders an interactive 3D model (GLTF/GLB, FBX, or OBJ) within an HDR environment stage with contact shadows, auto-framing, drag rotation, and subtle hover/float damping. Provides entrance animations ('rise', 'spin', 'fade') and canvas screenshot capture via an imperative ref handle.
**Props** — `url` (string, required) — remote URL or asset path to the 3D model file (.gltf, .glb, .fbx, .obj); `environment` (ModelViewerEnvironment, 'studio') — HDR environment map preset ('studio', 'apartment', 'night', etc.); `autoRotate` (boolean, true) — whether the model spins on turntable when idle; `dragRotate` (boolean, true) — enables pointer drag gestures to orbit around the object; `zoom` (boolean, true) — allows wheel/pinch zooming between minZoom and maxZoom bounds; `shadow` (boolean, true) — renders dynamic contact shadows beneath the model floor; `hoverTilt` (number, 0.15) — responsiveness of subtle camera tilt tracking cursor movement; `intro` ('rise' | 'spin' | 'fade' | 'none', 'rise') — initial reveal choreography.
**Motion** — WebGL via Three.js and React Three Fiber. Runs demand-based rendering or continuous rAF during auto-rotation, floating bob, and pointer drag interactions. Honors `prefers-reduced-motion` to disable auto-rotation and floating.
**Cost** — Massive bundle overhead: `three` (~160 KB gzip) + `@react-three/fiber` (~30 KB gzip) + `@react-three/drei` (~25 KB gzip), exceeding the site's entire 150 KB initial JS budget. Requires downloading large external 3D model and HDR environment assets. Client-only: Canvas mounts inside client DOM; SSR renders empty fallback div.
**Fit for ARKRETE** — no fit. ARKRETE is an interior contractor whose core premise is physical finished space captured in high-end photography ("Photography is the argument"). 3D CAD/model viewers belong to furniture e-commerce or gaming sites, and the 200+ KB Three.js stack would destroy the site's performance budget.
**Verdict** — skip — 200+ KB Three.js dependency and 3D asset pipeline have no place on a site where real photography is the argument.
