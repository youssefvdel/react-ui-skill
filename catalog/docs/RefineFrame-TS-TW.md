# RefineFrame
**Registry**: `RefineFrame-TS-TW` · **Deps**: `@hugeicons/react`, `@hugeicons/core-free-icons` · **Files**: `RefineFrame/RefineFrame.tsx`
**What it does** — Wraps an image in a fixed-aspect frame and steps it through four stages: a blocky mosaic sharpens level by level down to the crisp photograph, with a soft feathered seam and a light sweep crossing the frame as it resolves. A chip reads Queued / Generating / Refining / Ready, and the error stage offers Retry.
**Props** — `status` ('queued' | 'generating' | 'refining' | 'complete' | 'error', 'generating') — stage to resolve toward; `children` (ReactNode) — the `<img>` it samples; `aspectRatio` (string, '4 / 3') — reserved box, so no layout shift; `width` (number, 320) — frame width; `stageDuration` (number, 400) — ms per level; `sweep` (boolean, true); `showStatus` (boolean, true); `labels` (partial map, Queued/Generating/Refining/Ready) — chip copy.
**Motion** — Status-driven: an rAF loop advances a progress value and redraws a 2D canvas from nine downsampled copies, with a feathered seam and the glint bar; the wrapper cross-fades blur, saturation and scale through a CSS transition. Reduced motion jumps straight to the sharp frame. No GSAP, no Framer Motion.
**Cost** — Two Hugeicons packages for four chip glyphs, about 4.5 KB gzip of source. Nine full-size offscreen canvases are built per resize (48 px to 1 px pyramid), which is a few MB at the default 320 px but hundreds of MB full-bleed at DPR 2 — cap the width or force DPR 1. One rAF burst per stage change, none once resolved. The frame is CSS so it prerenders; only the canvas paint needs the client.
**Fit for ARKRETE** — Projects page grid and the home reel panels: keep the mosaic-to-sharp resolve, drop the chip and the generation wording, and drive `status` from the image's `onLoad` over the existing `Img` component.
**Verdict** — adapt — the one piece here with a real job: a photograph arriving without a flash of empty frame.
