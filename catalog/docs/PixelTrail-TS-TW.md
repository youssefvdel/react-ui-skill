# PixelTrail
**Registry**: `PixelTrail-TS-TW` · **Deps**: none · **Files**: `PixelTrail/PixelTrail.tsx`
**What it does** — An interactive WebGL2 canvas overlay that leaves a glowing trail of pixel tiles behind the cursor. Pixels dissolve through fading, shrinking, or Bayer matrix dithering, with optional fluid gravity flow and specular surface lighting.
**Props** — `gridSize` (number, 32) — density of the pixel grid across canvas width; `trailSize` (number, 0.1) — brush thickness and radius of the pointer trail; `maxAge` (number, 500) — lifetime of trail points in milliseconds before complete decay; `color` / `trailColor` (string, '#ffffff' / null) — foreground pixel colour and optional age gradient tint; `shape` ('square' | 'circle' | 'diamond', 'square') — geometric silhouette of trail cells; `decay` ('fade' | 'shrink' | 'dither', 'fade') — dissolution algorithm used as points age; `gooeyFilter` (object | false | null, null) — 2D error-function convolution producing organic metaball fusion; `gravity` / `flow` (number, 0 / 0) — downward acceleration and directional drift applied to active trail points.
**Motion** — WebGL2 fragment shader sampling a 512×512 trail history texture updated every frame via CPU pointer interpolation. Continuous RAF loop advances trail decay, physics flow, and sparkling noise, with multi-tap convolution passes for gooey blending. Has no reduced-motion fallback and runs continuously while pointer moves.
**Cost** — 26.0 KB source (~4.8 KB gzip), zero dependencies. Single `<canvas>` DOM element. Heavy GPU fragment shader with 49-tap convolution loops and per-frame CPU point buffer allocations. Client-only; blank on static prerender.
**Fit for ARKRETE** — No fit. An interactive cursor trail of sparkling, gooey pixels is a toy interaction that distracts from portfolio imagery and lacks reduced-motion support.
**Verdict** — skip — cursor toy with 49-tap WebGL2 convolution loops and no reduced-motion fallback.
