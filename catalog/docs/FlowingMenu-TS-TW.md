# FlowingMenu
**Registry**: `FlowingMenu-TS-TW` · **Deps**: @hugeicons/react@^1.1.10, @hugeicons/core-free-icons@^4.3.3 · **Files**: FlowingMenu/FlowingMenu.tsx
**What it does** — A full-height menu where each row is a page name at up to 140 px; hovering glides a liquid band between rows, and inside the band the same name, an image and a meta label scroll past in a marquee. Dividers, an index column and an arrow are optional.
**Props** — `items` ({ text, link, image, marquee, meta }[]) — the rows; `speed` (number, 60) — marquee pixels per second; `direction` ('left' | 'right' | 'alternate', 'left') — marquee direction; `duration` (number, 0.5) — seconds for the band's spring; `stretch` (number, 0.6) — how far the leading edge outruns the trailing one; `magnet` (number, 0.25) — how much the band leans toward the cursor; `carryContent` (boolean, false) — whether the marquee travels with the band between rows; `onItemClick` (item, index, event) — row handler.
**Motion** — Pointer-driven rAF, no library: the band is two spring-damped edges clipped with `clip-path`, the marquee is a duplicated track translated per frame, and an intro staggers the rows in. The loop only runs while a row is hovered and stops when idle; reduced motion kills the marquee, the magnet lean and the intro.
**Cost** — 27 KB of source, DOM and transforms only, one ResizeObserver, no canvas — the markup prerenders fine. The real cost is two icon packages for a single 22 px arrow, plus a full-height menu that needs its own overlay, focus trap and scroll lock around it.
**Fit for ARKRETE** — the nav overlay, if the five pages ever need a full-height menu with room photographs in the band.
**Verdict** — skip — the giant repeated label inside the band is decoration on top of a nav, and two icon packages for one arrow is not a 150 KB decision worth defending.
