# LightPillar
**Registry**: `LightPillar-TS-TW` · **Deps**: none · **Files**: `LightPillar/LightPillar.tsx`
**What it does** — Renders a swirling volumetric light pillar that twists vertically against a dark background with chromatic dispersion. The column leans toward the cursor on hover, surges outward with a bright radial shockwave on click, and blends across underlying content via screen compositing.
**Props** — `topColor` / `bottomColor` (string, '#5227FF' / '#FF9FFC') — two-point vertical chromatic gradient; `intensity` / `glowAmount` (number, 1.0 / 0.002) — core luminance and ambient halo spread; `pillarWidth` / `pillarHeight` (number, 3.0 / 0.4) — cylinder diameter and vertical framing; `rotationSpeed` / `twist` (number, 0.3 / 0.4) — axial spin velocity and helical warp rate; `detail` (number, 4) — raymarching loop iterations (1–6); `noiseIntensity` (number, 0.5) — procedural turbulence in the pillar walls; `interactive` / `clickPulse` (boolean, true / true) — pointer tilt tracking and click shockwave; `mixBlendMode` (CSSProperties['mixBlendMode'], 'screen') — canvas blend mode.
**Motion** — Single WebGL2 fragment shader evaluating raymarched cylinder distances and procedural noise on rAF; cursor offsets steer the pillar axis and clicks trigger a decaying radial wave. No external libraries. Reduced motion disables time rotation and click pulses, locking the pillar in a steady vertical stance.
**Cost** — Zero dependencies; 22.7 KB source (~5.5 KB gzip). Heavy raymarching loop executed per fragment; noticeable GPU load at high resolutions. Client-only; prerenders an empty div.
**Fit for ARKRETE** — no fit. A glowing sci-fi energy column acts as self-serving spectacle that distracts from architectural room photography.
**Verdict** — skip — sci-fi light column shader that competes with room photography and adds no architectural substance.
