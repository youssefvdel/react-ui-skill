# RippleGrid
**Registry**: `RippleGrid-TS-TW` · **Deps**: none · **Files**: RippleGrid/RippleGrid.tsx
**What it does** — Draws a full-bleed grid of hairlines, dots or crosshairs with a raw WebGL2 fragment shader, then bends and brightens it where waves pass through. Waves come from an interval timer, the pointer trail and clicks, and the plane can be tilted into perspective.
**Props** — `variant` ('lines' | 'dots' | 'cross', lines) — mark shape; `cellSize` (48) — grid pitch in px; `color` ('#ffffff') — line colour; `tilt` (0deg, clamped 0–80) — lays the grid on a receding plane; `autoRipple` ('center' | 'random' | 'none', center) — unattended waves; `rippleInterval` (2.6s) — their spacing; `mouseInteraction` (true) — cursor trail and lens; `paused` (false) — freezes the clock.
**Motion** — A clock ages each wave, and every ripple pushes a Gaussian packet through the grid coordinates, so the lines visibly displace and the halo brightens. Auto waves fire every 2.6 s from the centre, a small one per ~1.6 cells of pointer travel, a 1.2-strength one per click. rAF runs whenever the canvas is on screen and unpaused, stops on intersection exit and hidden tabs; reduced motion advances nothing and draws one static frame.
**Cost** — Zero dependencies, 18.7 KB of source, one fullscreen triangle and a single fragment pass at DPR ≤ 2 — cheap for a full-bleed layer, but it holds a permanent WebGL2 context and has no fallback: if the context or shader fails it returns an empty div. Client-only; prerender ships an aria-hidden canvas with nothing in it.
**Fit for ARKRETE** — no fit. A glowing technical grid reads as dashboard, not interiors, and its white cool-toned glow would compete with brass.
**Verdict** — skip — a decorative grid with no job on any of the five pages, and one more glow language competing with the single accent.
