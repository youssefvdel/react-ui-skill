# SwipeRow
**Registry**: `SwipeRow-TS-TW` · **Deps**: `motion@^12.23.12`, `@hugeicons/react@^1.1.10`, `@hugeicons/core-free-icons@^4.3.3` · **Files**: `SwipeRow/SwipeRow.tsx`
**What it does** — A list row that drags sideways to expose action buttons behind it, with rubber-band resistance and a spring snap at either end. Pull past 60% of the width and the primary action commits, the row collapses to nothing and a short haptic fires on touch.
**Props** — `actions` (`SwipeAction[]`, one Delete) — rail buttons with label, icon, colour and callback; `direction` (`left`|`right`, left) — which way it opens; `actionWidth` (number, 80) — rail width; `commitAt` (number, 0.6) — fraction of width that commits; `fullSwipe` (boolean, true) — allow the full-width delete; `open` / `onOpenChange` — controlled state; `onAction` / `onCommit` — select and commit callbacks; `haptic` (boolean, true) — `navigator.vibrate(8)` on commit.
**Motion** — motion/react `useMotionValue` + `animate` drive the row transform and rail spread; window pointer listeners track velocity, a spring settles snap-back, and the row animates height to collapse. Reduced motion resolves opens and closes instantly. Needs `motion` and two hugeicons packages.
**Cost** — `motion` (~30–40 KB gzip), `@hugeicons/react` and `@hugeicons/core-free-icons` (tree-shaken to one icon, but two installs), ~18 KB source. One row is cheap DOM; it is the dependencies and the pointer/velocity bookkeeping that cost. Renders on the server safely, interaction client-only.
**Fit for ARKRETE** — no fit. There is no list, no destructive action and no account surface anywhere on the five pages; the default red action rail is also a second accent.
**Verdict** — skip — a mobile app pattern with no row to swipe, bought with two icon packages and motion.
