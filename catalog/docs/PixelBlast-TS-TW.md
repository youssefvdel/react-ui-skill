# PixelBlast
**Registry**: `PixelBlast-TS-TW` · **Deps**: none · **Files**: `PixelBlast/PixelBlast.tsx`
**What it does** — A full-bleed WebGL2 grid of retro pixel glyphs that drift and undulate across the viewport driven by 3D fractional Brownian motion noise. Clicks emit expanding circular shockwave rings and pointer movement leaves a diffusing brush trail across the matrix.
**Props** — `variant` (PixelBlastVariant, 'square') — glyph shape: square, circle, triangle, diamond, cross, or ring; `pixelSize` (number, 3) — cell size for rasterization and simulation grid; `color` / `accentColor` (string, '#B1A990' / '#ffffff') — base and highlight glyph tints; `patternScale` / `patternDensity` (number, 2 / 1) — noise frequency and grid fill density; `enableRipples` (boolean, true) — whether clicks propagate circular shockwaves; `rippleSpeed` / `rippleThickness` (number, 0.4 / 0.12) — velocity and ring width of shockwaves; `hoverEffect` / `hoverRadius` ('reveal' | 'grow' | 'none', 'none' / 50) — pointer interaction mode and radius; `autoPauseOffscreen` (boolean, true) — freezes simulation when scrolled out of view.
**Motion** — Multi-pass WebGL2 shader pipeline using ping-pong framebuffers for cellular simulation and ripple decay. RequestAnimationFrame advances time for noise drift, decays up to ten concurrent click ripples, and diffuses pointer brush marks; reduced motion freezes simulation time.
**Cost** — 34.5 KB source (~6.1 KB gzip), zero dependencies. Single `<canvas>` DOM element, but continuous GPU load running multi-pass shader simulations every frame. Client-only; prerender outputs a blank container.
**Fit for ARKRETE** — No fit. 8-bit arcade pixel glyphs and shockwave ripples conflict with the dark luxury aesthetic and compete with architectural photography.
**Verdict** — skip — retro pixel simulation and click shockwaves that clash with quiet luxury interior imagery.
