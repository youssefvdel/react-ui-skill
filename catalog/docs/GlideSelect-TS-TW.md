# GlideSelect
**Registry**: `GlideSelect-TS-TW` · **Deps**: @hugeicons/react@^1.1.10, @hugeicons/core-free-icons@^4.3.3 · **Files**: GlideSelect/GlideSelect.tsx
**What it does** — A compact select chip that opens a small menu from its nearest corner, with a highlight pill that glides from row to row under the pointer or arrow keys. Options can carry a right-aligned tag, the chosen row shows a tick, and the menu flips above the trigger when there is no room below.
**Props** — `options` ((string | GlideSelectOption)[], One/Two/Three) — values, labels and optional tags; `value` / `defaultValue` (string, '') — controlled or uncontrolled selection; `onChange` ((value, option) => void) — fired on pick; `size` ('sm' | 'md' | 'lg', 'md') — chip and row height; `menuWidth` (number, 176) — menu width in px; `placement` ('top' | 'bottom', 'bottom') — preferred side, auto-flipped to fit; `rememberPosition` (boolean, true) — keep the last active row when the pointer leaves; `highlightColor` (string, #3f3f46) — pill and selected-row fill.
**Motion** — CSS only: the menu pops with a 180 ms scale/opacity transition, the pill glides with a 220 ms transform, and the trigger label blurs in over 160 ms. Pointer scrubbing sets the active row directly; reduced motion removes the pop scale and the pill glide. No animation library.
**Cost** — 15.4 KB of source plus two Hugeicons packages for exactly two glyphs (chevron and tick). One inline `<style>` per instance, one `pointerdown` listener while open, no portal. It calls `useLayoutEffect` unconditionally, so the vite-react-ssg prerender logs a server warning; the markup itself renders and hydrates.
**Fit for ARKRETE** — Contact, the inquiry form's "project type" field (residence, hospitality, office, retail): the gliding highlight is a calm, precise response that suits the dark form, and it replaces the unstyled native dropdown.
**Verdict** — adapt — right interaction for the one place a select is needed, but drop both icon packages for two inline SVGs and remove the tag chips.
