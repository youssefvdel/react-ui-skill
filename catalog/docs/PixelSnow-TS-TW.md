# PixelSnow
**Registry**: `PixelSnow-TS-TW` · **Deps**: none · **Files**: `PixelSnow/PixelSnow.tsx`
**What it does** — A WebGL2 canvas effect of falling pixel-art snowflakes that drift downward with wind sway and depth parallax. Flakes repel away from the pointer and can settle into a dithered snow pile along the bottom edge of the container.
**Props** — `variant` (PixelSnowVariant, 'snowflake') — sprite style: snowflake, square, or round; `color` (string, '#ffffff') — primary tint of flakes and snow pile; `density` (number, 1) — flake count multiplier, allocating up to 4000 flakes across five depth planes; `speed` / `wind` (number, 1 / 0) — vertical fall velocity and lateral wind drift; `sway` (number, 1) — amplitude of sinusoidal horizontal oscillation; `flakeSize` / `pixelSize` (number, 1 / 1) — flake scale multiplier and virtual pixel rasterization factor; `accumulate` (boolean, false) — whether landed flakes build up a settled snow mound; `mouseInteraction` (boolean, true) — whether the pointer pushes and repels flakes.
**Motion** — WebGL2 instanced sprite rendering with offscreen accumulation textures. CPU advances flake positions, wind sway, and pointer repulsion each RAF frame, while shaders unpack 2D sprite atlases and Bayer dither patterns; reduced motion freezes flake motion.
**Cost** — 32.9 KB source (~5.9 KB gzip), zero dependencies. Single `<canvas>` DOM element. Multi-pass WebGL2 pipeline with framebuffers, sprite atlas uploads, and per-frame CPU particle simulation. Client-only; blank on static prerender.
