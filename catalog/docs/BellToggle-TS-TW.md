# BellToggle
**Registry**: `BellToggle-TS-TW` · **Deps**: motion@^12.23.12, @hugeicons/react@^1.1.10, @hugeicons/core-free-icons@^4.3.3 · **Files**: BellToggle/BellToggle.tsx
**What it does** — A pill toggle whose bell glyph swings when armed, sends out two arcs of ring waves, crossfades one label into another and widens or narrows the pill to fit the new label. It can also carry a count badge that pops in and wobbles when the count rises.
**Props** — `offLabel` (string, "Notify me") — resting text; `onLabel` (string, "You'll be notified") — armed text; `size` ('sm' | 'md' | 'lg', 'md') — pill height and type scale; `background` (string, `#27272a`) — resting fill; `onBackground` (string, `#f5f5f5`) — armed fill; `count` (number, 0) — badge value, shown as 9+ past nine; `badge` (boolean, true) — show the count bubble; `ringAmplitude` (number, 17) — degrees of the bell's first swing.
**Motion** — Press-driven. The bell swings through five decaying rotations with the Web Animations API, each pass firing an offset arc; the label clip is a Motion spring on `clip-path`, labels crossfade with a 2px blur, and the badge uses CSS transitions. Reduced motion jumps state with no swing, and keyboard toggles skip the ring.
**Cost** — Only 4 KB gzipped of its own source, but three packages: `motion` for one spring plus both Hugeicons packages for a single bell glyph. If Motion is not already in the shell that is roughly 30 KB gzipped for a toggle. Client-only; it measures both labels with a ResizeObserver and the document-font promise, so server markup is a best guess at width.
**Fit for ARKRETE** — No fit — the inquiry form needs a submit, not a notification gimmick, and there is no mailing list to notify.
**Verdict** — skip — a ringing-bell joke with two icon packages behind it, on a site that never asks anyone to be notified.
