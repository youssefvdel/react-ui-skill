# Lightfall
**Registry**: `Lightfall-TS-TW` · **Deps**: none · **Files**: `Lightfall/Lightfall.tsx`
**What it does** — Renders streaks of light cascading down a curved tunnel perspective like digital rain or falling stars. Streaks bend around the cursor via magnetic deflection, and holding down the pointer ramps velocity into high-speed warp trails with multi-pass bloom.
**Props** — `colors` (string[], ['#ffffff']) — array of streak tints (up to 8 colors); `backgroundColor` (string, '#94a3b8') — background field tint; `speed` / `streakCount` (number, 0.3 / 2) — fall rate and streak stream density multiplier; `streakWidth` / `streakLength` (number, 0.8 / 1) — beam thickness and trail duration; `glow` / `bloom` / `headGlow` (number, 1 / 0.35 / 0.6) — particle halo, multi-level bloom intensity, and leading-edge brightness; `density` / `twinkle` (number, 0.6 / 0.3) — streak frequency and random shimmer; `mouseInteraction` / `mouseStrength` (boolean / number, true / 0.4) — cursor deflection toggle and magnetic force; `holdToWarp` (boolean, true) — whether holding the pointer triggers hyperspace acceleration.
**Motion** — WebGL2 pipeline with downsampled multi-pass bloom framebuffers and time-integrated streak coordinates on rAF; holding the pointer smoothly scales velocity and trail elongation. No external libraries. Reduced motion halts fall progression, suppresses warp acceleration, and disables cursor magnetic deflection.
**Cost** — Zero dependencies; 28.2 KB source (~6.8 KB gzip). Heavy WebGL2 rendering with 4-level bloom downsample and upsample passes; substantial GPU fillrate and memory bandwidth footprint. Client-only; prerenders an empty div.
**Fit for ARKRETE** — no fit. Sci-fi warp speed rain and neon streak tunnels distract completely from physical interior architecture and materials.
**Verdict** — skip — sci-fi light warp spectacle with heavy GPU cost and no connection to interior fit-out.
