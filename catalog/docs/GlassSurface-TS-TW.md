# GlassSurface
**Registry**: `GlassSurface-TS-TW` · **Deps**: none · **Files**: GlassSurface/GlassSurface.tsx
**What it does** — A rounded panel of Apple-style liquid glass that bends and splits the colour of whatever sits behind it, with a bright rim and a soft inner shade. Given a logo image it traces the shape and builds a matching glass outline, so the panel can take any silhouette rather than a rounded rectangle.
**Props** — `width` / `height` (number | string, 200 × 80) — panel size; `borderRadius` (number, 20) — corner radius; `blur` (number, 11) — edge softening in the displacement map; `displace` (number, 0) — extra Gaussian blur inside the glass; `saturation` (number, 1) — colour boost behind the glass; `renderer` ('auto' | 'svg' | 'webgl', 'auto') — displacement path; `shape` (string, none) — image URL to trace into a glass outline; `mixBlendMode` (CSS mix-blend-mode, 'difference') — how the red/blue edge layers combine.
**Motion** — Nothing animates on its own; the panel is static and re-renders its displacement map when it resizes or a prop changes, with a 260 ms opacity fade when a traced shape finishes loading. Reduced motion needs no special case.
**Cost** — 36.5 KB, no packages. The SVG path runs `feImage` + three `feDisplacementMap` + `feGaussianBlur` through `backdrop-filter: url(#id)`, which Chromium supports but Safari does not; it detects that and falls back to a plain blur-and-frost panel. It rebuilds an SVG data URI on every resize, and `shape` rasterises then traces the image on the main thread. The WebGL path only refracts a supplied `<img>`, `<video>` or `<canvas>`, not the DOM behind it.
**Fit for ARKRETE** — No fit as shipped. A glass scrim over the home room reel would distort the photography, and the default red/green/blue offsets add colour the palette does not allow; a fixed nav needs six lines of `backdrop-filter: blur()` and a near-black tint, not a traced displacement map.
**Verdict** — skip — beautiful demo, but CSS backdrop blur does the only job this site has for glass at effectively zero cost.
