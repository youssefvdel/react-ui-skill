# GlitchText
**Registry**: `GlitchText-TS-TW` · **Deps**: none · **Files**: GlitchText/GlitchText.tsx
**What it does** — Display text that tears itself apart at random intervals: horizontal slices slip sideways with red and cyan ghosts, or the whole word splits into channels, a scan band sweeps down it, or single characters swap to punctuation glyphs. It can run constantly, only on hover, or burst for a moment on click.
**Props** — `children` (string, required) — the headline; `mode` ('slices' | 'rgb' | 'scan' | 'noise', 'slices') — which tear; `intensity` (number, 0.5) — frequency and travel of the glitch; `speed` (number, 0.5) — interval between steps; `offset` (number, 10) — maximum pixel displacement; `trigger` ('always' | 'hover' | 'click', 'always') — what sets it off; `shadowColors` ([string, string], ['#ff0000', '#00ffff']) — the two ghost colours; `flicker` (boolean, false) — random opacity drops.
**Motion** — A rAF loop writes mask band positions, translates, skew and opacity into 13 CSS custom properties on three stacked copies of the text; `noise` mode also swaps `data-glyph` per character. Random events fire on a timer scaled by `speed`. Reduced motion rests immediately on the clean text, and offscreen instances stop.
**Cost** — 15.8 KB, no packages. Three text layers plus one span per character in noise mode; 13 style writes per frame while active, with a diff guard so unchanged values are skipped. Prerenders as ordinary text, so the no-JS and reduced-motion state are both correct.
**Fit for ARKRETE** — No fit. Red/cyan channel split adds two accents to a one-accent palette, and the glitch language reads gaming or cyber, the opposite of the firm's calm.
**Verdict** — skip — the effect's whole value is the noise it adds, which is exactly what this site is trying to remove.
