# CircularGallery
**Registry**: `CircularGallery-TS-TW` · **Deps**: none · **Files**: CircularGallery/CircularGallery.tsx
**What it does** — Displays an infinitely looping ribbon of curved cards inside a WebGL2 canvas that can be dragged, scrolled, or clicked to expand. Cards distort along an interactive cylindrical bend and sine wave ripple while HTML text labels track them above.
**Props** — `items` (GalleryItem[], demo items) — item array with image, title, and description; `bend` (number, 3) — ribbon curvature toward or away from camera; `wave` (number, 0) — vertical sine wave displacement amplitude; `scrollSpeed` (number, 2) — scroll sensitivity multiplier; `scrollEase` (number, 0.08) — inertia easing smoothing factor; `snap` (boolean, false) — magnetically locks nearest card on stop; `openOnClick` (boolean, true) — expands clicked card into full-bleed view; `dpr` (number, undefined) — device pixel ratio cap.
**Motion** — Continuous WebGL2 rAF render loop during movement, passing uniforms for vertex displacement (bend, wave, angle), SDF corner rounding, shadows, and smoothstep edge fading. Triggered by drag, wheel, arrow keys, or auto-scroll. Reduced motion skips intro and disables easing. No external libraries.
**Cost** — Zero npm dependencies, 45 KB source; creates an active WebGL2 context, multiple textures, and instanced mesh geometry; high GPU draw overhead. Client-only canvas (prerenders blank).
**Fit for ARKRETE** — no fit. Arkrete showcases rooms through deliberate vertical stacks and horizontal reels; a wavy 3D WebGL ribbon is an experimental distraction that threatens the 150 KB initial JS budget.
**Verdict** — skip — 45 KB WebGL ribbon with undulating sine-wave geometry clashes with Arkrete's quiet editorial room reels and strains bundle weight.
