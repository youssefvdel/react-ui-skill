# BranchedMenu
**Registry**: `BranchedMenu-TS-TW` · **Deps**: @hugeicons/react@^1.1.10, @hugeicons/core-free-icons@^4.3.3 · **Files**: BranchedMenu/BranchedMenu.tsx
**What it does** — A vertical menu in which each section folds open to show its children, with thin SVG elbows branching off a trunk to every child. The selected child's branch draws itself in the accent colour while a small marker glides down the trunk to the open section.
**Props** — `items` (BranchedMenuItem[], a docs tree) — sections, optional values and children with optional icons; `defaultOpen` (number | number[], 0) — sections open at mount; `width` (number, 240) — max menu width; `rowHeight` (number, 36) — child row height; `indent` (number, 40) — px where branch lines end; `accentColor` (string, `#f5f5f5`) — active branch and label; `lineColor` (string, `#3f3f46`) — trunk and idle branches; `drawDuration` (number, 400) — ms for the branch draw.
**Motion** — Open and close is a CSS `grid-template-rows: 0fr → 1fr` fold; selection animates `stroke-dashoffset` on the branch path and the marker's `top`. No rAF, no library. `motion-reduce` removes the fold and draw transitions; the marker keeps a short opacity fade. Icons render through Hugeicons only when a child supplies one.
**Cost** — About 3 KB gzipped of source plus both Hugeicons packages for eight sample icons — tree-shaken, but a second icon dependency on top of whatever the site already uses. One SVG per open section and a fixed body height derived from `rowHeight × children`, so wrapping labels overflow rather than grow. Client-only open state; the closed menu prerenders cleanly.
**Fit for ARKRETE** — Services, a five-trade index with each trade's scope items — but only if the page actually carries a side index.
**Verdict** — skip — five flat pages need five links, not a branching tree with icons and a travelling marker.
