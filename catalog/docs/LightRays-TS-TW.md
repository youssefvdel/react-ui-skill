# LightRays
**Registry**: `LightRays-TS-TW` · **Deps**: none · **Files**: `LightRays/LightRays.tsx`
**What it does** — Projects volumetric God rays streaming inward from any screen edge through hazy atmospheric scattering. Moving the pointer tilts the light direction and casts a dark occlusion shadow behind the cursor, while clicking pulses ray intensity.
**Props** — `raysOrigin` (RaysOrigin, 'top-center') — edge anchor point ('top-center', 'top-left', 'left', etc.); `raysColor` (string, '#ffffff') — light ray color tint; `raysSpeed` (number, 1) — rotational drift speed of ray harmonics; `lightSpread` / `rayLength` (number, 0.5 / 3) — angular fan spread and ray reach; `rayDensity` / `raySharpness` (number, 1 / 0.35) — streak frequency and edge definition; `glow` / `haze` / `atmosphere` (number, 0.6 / 0.25 / 1) — source brightness, ambient wash, and particle scattering; `followMouse` / `cursorShadow` (boolean, true / true) — cursor direction tracking and pointer shadow casting; `pulsating` / `clickPulse` (boolean, false / true) — cyclic ambient breathing and click surge.
**Motion** — Procedural WebGL2 shader evaluating radial ray harmonics, atmospheric falloff, and cursor occlusion on rAF; click surges decay exponentially. No external libraries. Reduced motion drops animation speed to 0.35× and suppresses click pulses, but fails to stop completely unless speed is set to 0.
**Cost** — Zero dependencies; 22 KB source (~5.2 KB gzip). Single fullscreen WebGL2 canvas pass; moderate GPU fragment evaluation. Client-only; prerenders an empty placeholder div.
