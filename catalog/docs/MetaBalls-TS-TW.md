# MetaBalls
**Registry**: `MetaBalls-TS-TW` · **Deps**: none · **Files**: MetaBalls/MetaBalls.tsx
**What it does** — Renders liquid organic blobs on a WebGL2 canvas that drift, fuse together with surface tension, and stretch apart when colliding. A cursor-following blob pushes and pulls the field on hover, with interactive springs simulating wobble, stickiness, and click bursts.
**Props** — `color` (string, '#ffffff') — fill or outline color for the autonomous fluid balls; `cursorBallColor` (string, '#ffffff') — tint of the interactive pointer-driven metaball; `ballCount` (number, 15) — number of simulated metaball bodies (up to 50); `variant` ('solid' | 'outline' | 'contour', 'solid') — visual style (filled silhouettes, outline borders, or topographic contour rings); `motion` ('orbit' | 'drift' | 'lava', 'orbit') — procedural trajectory pattern governing particle drift; `gooeyness` / `stickiness` (number, 0.5 / 0.5) — threshold and pull force controlling fluid fusion between adjacent spheres; `speed` (number, 0.3) — global simulation and orbit velocity multiplier; `enableMouseInteraction` (boolean, true) — enables cursor tracking and pointer collision dynamics.
**Motion** — WebGL2 fragment shader evaluating implicit distance fields continuously on requestAnimationFrame. CPU physics loop computes body velocities, spring wobble, and particle repulsion each frame. Mousemove updates cursor coordinates with lerped smoothing; click triggers an instantaneous velocity burst. No GSAP or Framer Motion. Runs continuously but it does read `prefers-reduced-motion`: the intro is skipped, though the blobs keep drifting afterwards.
**Cost** — 662 lines (~24 KB source), zero external dependencies. Heavy per-pixel distance evaluation loop in WebGL2 across up to 51 bodies causes substantial GPU fill-rate consumption and mobile battery drain. Client-only: SSR emits an empty container div; WebGL context initializes in useEffect.
**Fit for ARKRETE** — no fit. Organic lava-lamp fluid blobs and gooey slime physics belong to experimental creative coding demos; they directly undermine ARKRETE's architectural identity founded on crisp geometric joinery, physical stone, and quiet restraint.
**Verdict** — skip — organic lava-lamp shader gimmick that contradicts ARKRETE's architectural geometry and drains GPU fill rate.
