# CodeSlots
**Registry**: `CodeSlots-TS-TW` · **Deps**: `motion@^12.23.12`, `@hugeicons/react@^1.1.10`, `@hugeicons/core-free-icons@^4.3.3` · **Files**: CodeSlots/CodeSlots.tsx
**What it does** — Provides a one-time passcode verification input where individual digits bounce into segmented slot boxes with spring physics. It handles paste events, SMS autofill, horizontal error shake, and a checkmark completion transition.
**Props** — `length` (number, 6) — number of digit slots in the passcode sequence; `value` (string, undefined) — controlled passcode value string; `status` ('idle' | 'error' | 'success', 'idle') — state controlling neutral, error shake, or checkmark styles; `mask` (boolean, false) — obscures entered digits with bullet dots; `caret` (boolean, true) — displays blinking vertical cursor in active slot; `slotSize` (number, 44) — width and height of each square slot box in pixels; `gap` (number, 8) — spacing in pixels between adjacent slot boxes; `onComplete` ((code: string) => void, undefined) — callback fired when all slots are filled.
**Motion** — Framer Motion spring transitions animating vertical bounce on character entry, horizontal shake keyframes on error, and checkmark reveal on success. Reduced motion disables springs and shakes, snapping digits immediately. Requires Framer Motion.
**Cost** — Requires `motion` (~30 KB gzip) and two `@hugeicons` packages (~18 KB source); mounts hidden input layered over animated slot elements. Prerenders static slot containers, but springs and focus handling are client-only.
**Fit for ARKRETE** — no fit. Arkrete is an informational portfolio with an inquiry form; the site has no user accounts, client portals, or authentication flows requiring OTP code entry.
**Verdict** — skip — OTP passcode verification input has no role on a portfolio site with no user authentication or login flows.
