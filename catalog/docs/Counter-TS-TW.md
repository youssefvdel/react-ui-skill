# Counter
**Registry**: `Counter-TS-TW` · **Deps**: none · **Files**: `Counter/Counter.tsx`
**What it does** — Odometer digits: every decimal place is a vertical strip of 0–9 that rolls to its new value with spring overshoot, staggered right to left, and blurs with speed. Numbers are formatted through `Intl.NumberFormat`, so currency, separators, decimals and non-Latin numerals all work.
**Props** — `value` (number, 0) — the reading. `locale` (string, 'en-US') — numeral system and grouping. `format` (Intl.NumberFormatOptions) — currency, percent, unit. `decimals` / `minDigits` (undefined / 1) — fixed fraction and padding. `direction` ('auto' | 'up' | 'down' | 'shortest', 'auto') — which way digits travel. `duration` (number, 0.7), `bounce` (0.2), `stagger` (0.04) — spring feel. `intro` (boolean, true) — one full turn at 50% visibility. `fontSize` (number, 100) — type size in px.
**Motion** — A hand-written spring integrator on RAF, per digit, with width interpolation so proportional fonts do not jump and a `feGaussianBlur` whose radius comes from velocity; the intro fires from IntersectionObserver once. Reduced motion zeroes position and blur, and the RAF stops when everything settles — a genuinely calm static state.
**Cost** — Zero dependencies, ~21 KB of source, but heavy DOM for a number: ten absolutely-positioned numerals per digit plus a hidden measure row, a `ResizeObserver` and a `document.fonts.ready` wait. The accessible value is an `sr-only` string, so it degrades to readable text without motion. Client-side measurement makes the visible version effectively client-only.
**Fit for ARKRETE** — No fit. It exists to make a figure feel expensive, and the site shows no figures.
**Verdict** — skip — the best-built thing in the batch, aimed at a number ARKRETE never displays.
