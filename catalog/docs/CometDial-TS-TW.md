# CometDial
**Registry**: `CometDial-TS-TW` · **Deps**: motion@^12.23.12 · **Files**: `CometDial/CometDial.tsx`
**What it does** — A circular slider: grab the ring anywhere off-centre and drag or flick, and a lit arc, a head dot and a tapered comet tail chase the value, with the number and unit centred inside. Releasing lets momentum carry the value and a spring settle it back onto the step grid.
**Props** — `value` / `defaultValue` (number, 62) — controlled or seeded reading. `min` / `max` (0 / 100), `step` (1) — snap grid and decimal places. `sweep` (number, 320) — degrees of arc, the rest is a dead gap. `accent` / `ink` (string, #f5f5f5 / #fdfdfd) — lit arc versus track. `size` (number, 250) — diameter in px. `momentum` (number, 1) — how far a flick throws. `cometReach` / `cometWidth` (180 / 12) — tail length and thickness. `onChangeEnd` (fn) — fires with `{ velocity, bounce }`.
**Motion** — Drag, flick and arrow keys all drive a Motion spring whose stiffness and damping are computed from `speed` and `tapBounce`/`flickBounce`; the twelve tail segments re-path only while the value is moving and the RAF parks when it settles. `useReducedMotion` jumps straight to the value with no spring, so it has a calm static version. Requires motion's `animate` and `useMotionValue`.
**Cost** — motion@12 is a new dependency; the `animate` + `useMotionValue` path is roughly 20–25 KB gzip. Twelve extra SVG paths mutated per frame during interaction only, `role="slider"` with full keyboard and ARIA wiring. The ring prerenders, but the centre figure is empty until the first paint effect, so static HTML shows a blank number.
**Fit for ARKRETE** — No fit. Nothing on the site is a bounded quantity a visitor would want to dial.
**Verdict** — skip — a well-built control looking for a number, and ARKRETE has none.
