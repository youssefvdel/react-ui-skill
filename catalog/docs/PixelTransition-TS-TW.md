# PixelTransition
**Registry**: `PixelTransition-TS-TW` · **Deps**: none · **Files**: `PixelTransition/PixelTransition.tsx`
**What it does** — Switches between two content layers by drawing a 2D canvas overlay of solid pixel blocks that pop or grow to cover the screen, swaps the underlying layer at the midpoint, and uncovers the new content. Patterns include random noise, ordered dithering, radial ripples, and directional wipes.
**Props** — `firstContent` / `secondContent` (ReactNode, required) — front and back content layers to transition between; `gridSize` (number, 10) — horizontal column count determining pixel cell size; `pixelColor` (string, '#ffffff') — base fill colour for the curtain pixels; `mosaic` (number, 0) — tonal variation factor generating multi-shade mosaic pixels; `animationStepDuration` (number, 0.4) — duration in seconds for each half of the transition; `pattern` (PixelTransitionPattern, 'random') — ordering logic: 'random', 'dither', 'ripple', or 'wipe'; `pixelAnimation` (PixelTransitionAnimation, 'pop') — per-pixel entrance style: 'pop', 'grow', or 'fade'; `pixelShape` (PixelTransitionShape, 'square') — geometric shape: 'square', 'rounded', or 'circle'.
**Motion** — An HTML5 Canvas 2D requestAnimationFrame loop that draws Path2D rectangles or arcs for each grid cell across two phases (sealing then unsealing). Triggered by pointer hover or click. If prefers-reduced-motion is detected, it skips the canvas draw and swaps layer visibility immediately.
**Cost** — 15.4 KB source (~3.3 KB gzip), zero dependencies. Two DOM content containers plus one `<canvas>` overlay. Idle when resting with zero CPU cost, but consumes CPU during active wipes drawing hundreds of Path2D paths per frame. First layer prerenders cleanly on server.
**Fit for ARKRETE** — No fit. An 8-bit blocky pixel curtain wipe between photographs or cards contradicts ARKRETE's refined architectural atmosphere.
**Verdict** — skip — blocky retro pixel wipe that conflicts with ARKRETE's refined architectural photography.
