# StickerPeel
**Registry**: `StickerPeel-TS-TW` · **Deps**: none · **Files**: `StickerPeel/StickerPeel.tsx`
**What it does** — Draws a transparent PNG as a die-cut sticker on its own WebGL canvas; moving near an edge curls the vinyl back, and pressing then dragging peels it off, swings it on release and lets it drop. Gloss, matte and holographic finishes light the curl and cast a soft shadow behind it.
**Props** — `imageSrc` (string, required) — the cut-out artwork; `width` (number, 200) — sticker size in px; `finish` (`gloss`|`matte`|`holo`, gloss) — surface reflection; `peelDirection` (number, 0) — angle of the peel edge; `peelBackHoverPct` / `peelBackActivePct` (number, 25 / 40) — how far it curls on hover and while dragged; `curlRadius` (number, 12) — tightness of the roll; `draggable` (boolean, true) plus `swing`, `friction`, `bounce` — throw physics; `backColor` (string, #d4d4d8) — the peeled underside.
**Motion** — All of it: a spring simulation drives curl, lift and swing, and a 96×96 vertex mesh bends the image in the shader. Triggered by pointer proximity, press-drag, release and an intro settle; the loop sleeps once the springs settle and when the sticker is off-screen. Needs WebGL2, no GSAP, no Framer Motion.
**Cost** — No npm dependency, ~41 KB of TSX source, but a WebGL2 context, two render targets and four draw passes per frame; up to a 1024 px texture. The root is `position: absolute` with a separate hit layer, so the parent must be `relative`; canvas is client-only (effects only, no SSR markup) and needs a reduced-motion static frame.
**Fit for ARKRETE** — no fit. A peelable sticker is a playful, tactile gag; there is no surface on home, projects, services, about or contact where a draggable vinyl decal carries the photography.
**Verdict** — skip — a 40 KB shader toy that needs cut-out PNGs and a playful brand, neither of which ARKRETE has.
